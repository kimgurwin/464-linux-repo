Included Files: 
README.txt - (This*) Text file containing the list of included files.
COPYRIGHT.txt - Text file containing copyright information providing rights to the “Hands on Robotics” course and further use of data.
2025-P1-green-Resources.pdf - PDF file containing the resources referenced through the project cycle. These include academic articles as well as past reports from previous teams.
2025-P1-green-team-photo.png - Image of 2025 Green team. 
2025-P1-green-brainstorming.pdf - PDF file of the brainstorm presentation.
2025-P1-green-final.pdf - PDF file of the final presentation report.
validation-check-results.txt - Text file generation of the results of the instructor provided archive check.
AI-check-claims.pdf - The LLM response regarding finding unsupported claims.
AI-check-writing.pdf - The LLM response regarding formatting, syntax, and any technical writing errors.
AI-check-zip.pdf - The LLM response to validating the contents of the submitted zip archive file.

src - Folder
OVERVIEW.txt - Text file containing the file identification information. 
USAGE.txt - Text file including the command order and execution of the robot code. User interface and keyboard control instructions are also included. 
INSTALL.txt - Text file describing the necessary installation and libraries necessary to run the provided code.
green_step.py - Python script file containing the script used to estimate gait metrics for the robot.
robotCommands.py - A Python file containing the logic for running the physical robot.
robotSimulator.py - A python file that contains the simulation of a robot   

howto - Folder
2025-P1-green-howto.pdf - PDF file containing the build instructions for constructing the P1 Green robot. 

tex - Folder
